01준비물

아래 다섯 가지가 갖춰져야 프로그램이 돕니다. 시작 버튼을 누르면 프로그램이 스스로 점검해서 빠진 것을 빨간색으로 알려줍니다.

항목내용
IDPW.txt네이버 아이디와 비밀번호를 한 줄씩 번갈아 적습니다. 여러 계정을 넣으면 하나가 막혔을 때 다음 계정으로 자동 전환됩니다.
setting.txt키워드·발행 간격·텔레그램 등 전체 설정. 아래 02에서 줄별로 설명합니다.
text.txt답변 끝에 붙일 홍보 문구. 5줄 구성입니다.
크롬PC에 설치돼 있어야 합니다. 드라이버는 프로그램이 알아서 맞춰 받습니다.
AI 엔진GPT·바드는 API 키가, ChatGPT 사이트·학습클로드는 해당 사이트 로그인이 필요합니다.
참고

텔레그램은 없어도 프로그램이 돕니다. 다만 자리를 비운 사이 캡차나 계정 문제가 생기면 알 방법이 없으니, 실제로 돌리실 거면 설정해두시는 편이 낫습니다.

10번째 키워드 · secret

10번째 키워드 칸에 secret 이라고 적어두면 크롬 창이 화면에 뜹니다. 프로그램이 질문을 찾고, 답을 만들고, 등록하는 과정을 눈으로 볼 수 있습니다.

secret 을 지우면 크롬이 백그라운드로 숨어서 아무것도 보이지 않습니다. 화면은 깔끔하지만 뭘 하고 있는지 알 수 없습니다.

secret 을 넣고 돌리시길 권합니다. 캡차가 떴는지, 로그인이 풀렸는지, 답변이 제대로 들어가는지를 바로 확인할 수 있어야 문제가 생겼을 때 대처가 됩니다. 익숙해진 뒤에 지우세요.

3

답변 모드 고르기

화면 오른쪽에서 하나만 고릅니다. 등급을 올리는 게 목적이라면 실시간 QnA답변입니다. 이유는 03에서 설명합니다.

  • 실시간 QnA답변 — 방금 올라온 질문을 계속 잡아 답변합니다.
  • 키워드 검색 답변 — 특정 키워드로 검색된 질문에만 답변합니다.
  • 최신글 1개씩 반복 — 키워드로 찾은 가장 최신 질문 1개에 답하고, 발행 간격만큼 쉬었다가 다시 1개.

사전작업 버튼을 누르면 크롬이 열립니다. 아이디·비밀번호·캡차를 직접 입력해 로그인하면, 로그인된 것을 감지해 쿠키를 저장합니다. 이후에는 이 쿠키로 자동 로그인합니다.

계정을 바꾸거나 한동안 안 돌렸다면 다시 해주세요.

03등급 빨리 올리는 법

이 프로그램으로 가장 큰 차이를 만드는 부분입니다. 핵심은 두 가지, 언제 도느냐와 몇 번째로 답하느냐입니다.

핵심 원칙

새벽에 돌리고, 첫 번째로 답한다

지식iN에서 등급을 끌어올리는 건 결국 답변 수와 채택률입니다. 그리고 이 두 가지를 동시에 밀어올리는 가장 확실한 방법이 경쟁이 적은 시간대에 먼저 답변을 다는 것입니다.

질문자는 보통 먼저 달린 답변부터 읽습니다. 답변이 세 개, 네 개 붙은 뒤에 끼어들면 읽히지도 채택되지도 않습니다. 반대로 첫 답변이면 질문자가 반드시 봅니다. 채택 확률이 근본적으로 달라집니다.

012345 67891011 121314151617 181920212223
선점 확률 높음 — 01~07시 보통 경쟁 많음

※ 시간대 구분은 운영 경험에 따른 기준입니다. 분야마다 다를 수 있으니 본인 키워드로 며칠 돌려보며 조정하세요.

왜 새벽인가

  • 답변자가 거의 없습니다. 낮에는 같은 질문에 여러 명이 달라붙지만, 새벽에는 올라온 질문이 한참 방치됩니다.
  • 질문은 계속 올라옵니다. 잠 못 자는 사람, 밤샘 작업자, 급한 상담이 새벽에 몰립니다. 공급은 있는데 답변자가 없는 시간입니다.
  • 첫 답변이 아침까지 남습니다. 새벽에 단 답변은 질문자가 아침에 일어나 확인할 때 맨 위에 있습니다.

첫 번째 키워드는 스페이스바 하나

가장 빠른 방법입니다. 1번 키워드 칸에 스페이스바를 한 번만 치고 비워두세요.

지식iN 질문에 띄어쓰기가 없는 경우는 거의 없습니다. 검색어를 공백 하나로 두면 사실상 올라오는 모든 질문이 걸립니다. 특정 분야 질문이 올라오길 기다릴 필요 없이, 새 질문이 뜨는 족족 바로 답을 답니다.

  • 물량이 최대가 됩니다. 등급은 결국 답변 수로 올라갑니다.
  • 새벽에 이 설정으로 돌리면 올라오는 질문마다 첫 답변을 잡습니다. 앞의 두 가지가 곱해집니다.
  • 첫 답변은 질문자가 반드시 보기 때문에 채택률도 같이 올라갑니다.
함께 볼 것

모든 분야의 질문이 들어옵니다. 프롬프트나 text.txt가 특정 업종에 맞춰져 있으면 엉뚱한 답이 나갈 수 있습니다. 이 설정으로 돌릴 때는 프롬프트를 범용으로 두세요.

나머지 키워드는 분야를 가리지 마세요

2~10번 키워드도 마찬가지입니다. 등급을 올리는 초반에는 특정 카테고리만 파는 것보다 폭넓게 답하는 쪽이 빠릅니다. 키워드를 좁게 잡으면 새벽에 잡히는 질문 자체가 몇 개 안 됩니다.

  • 남는 칸은 서로 다른 분야로 채우세요. 한 분야에 몰면 물량이 안 나옵니다.
  • 10번 칸은 secret 자리로 비워두세요 (02 참고).
  • 답변 개수가 쌓이고 등급이 올라간 뒤에, 수익이 되는 분야로 좁혀가는 순서가 좋습니다.
주의

답변 품질을 포기하면 역효과입니다. 질문과 상관없는 답변이 쌓이면 채택률이 떨어지고, 신고가 누적되면 계정 자체가 막힙니다. 물량은 시간대로 벌고, 품질은 프롬프트로 잡으세요. 채택률이 곧 등급입니다.

발행 간격은 너무 짧게 두지 마세요

setting.txt 11번째 줄이 발행 간격(초)입니다. 짧을수록 많이 올라가지만, 네이버가 하루 발행량 초과 알림을 띄우면 그날은 그 계정으로 더 못 올립니다. 프로그램이 이 알림을 감지해 화면과 텔레그램으로 알려줍니다.

계정을 여러 개 넣어두면 한 계정이 한도에 걸렸을 때 다음 계정으로 넘어가므로, 간격을 무리하게 줄이는 것보다 계정을 늘리는 쪽이 안전합니다.

룰렛 이용권도 같이 챙기세요

룰렛 얻기 체크박스를 켜면 이용권 조건을 자동으로 채웁니다. 네이버 규칙은 이렇습니다.

항목조건
이용권 1개질문 또는 답변 1개 이상 등록 ＋ 도움돼요/아니에요 5개 이상
하루 한도아이디당 최대 3개
소멸다음 달로 넘어가면 사라집니다

한도에 걸리면 프로그램이 체크를 자동으로 끄고, 날짜가 바뀌면 다시 켭니다.

04글작성 패턴

답변이 화면에 어떤 모양으로 나갈지 정합니다. 화면 가운데 글작성 패턴1 / 패턴2 라디오로 고릅니다.

패턴 1 · 기존

기호 소제목 + 평문 목록

소제목 앞에 ■를 붙이고, 목록은 - 와 1. 을 글자로 찍습니다.

■ 재질별 특징
- 편백나무 — 칼날에 부드러움
- 고무 — 관리가 쉬움

■ 구매 순서
1. 용도 정하기
2. 크기 정하기
패턴 2 · 신규

구분선 소제목 + 진짜 목록

소제목을 구분선으로 감싸고, 목록은 에디터가 직접 그리는 진짜 글머리 기호로 들어갑니다. 들여쓰기가 살아서 훨씬 읽기 좋습니다.

───────────────
▣ 재질별 특징
───────────────

  • 편백나무 — 칼날에 부드러움
  • 고무 — 관리가 쉬움

───────────────
▣ 구매 순서
───────────────

  1. 용도 정하기
  2. 크기 정하기

두 패턴 모두 표와 굵은 글씨는 그대로 반영됩니다. 목록 항목 안의 굵은 글씨도 유지됩니다.

추천

같은 계정으로 오래 돌리면 답변 모양이 똑같아 보입니다. 가끔 패턴을 바꿔주면 글이 단조로워 보이지 않습니다. 읽기 편한 쪽은 패턴2입니다.

05막힐 때

자주 나오는 상황과 원인입니다. 대부분 프로그램이 알아서 넘어가지만, 계속 반복되면 아래를 확인하세요.

답변이 안 달리고 계속 넘어갑니다

  • 전문가 전용 분야 — 답변 등록 버튼 자체가 없는 질문입니다. 오류가 아니라 정상이며, 재시도해도 버튼이 생기지 않으므로 프로그램이 바로 건너뜁니다.
  • 비공개 질문 — 등록을 시도하면 “로그인 필요” 알림이 뜹니다. 로그인 문제가 아니라 네이버가 비공개를 이렇게 표시하는 것입니다.
  • 이미지가 있는 질문 — 사진을 봐야 답할 수 있는 질문은 엉뚱한 답이 나가지 않도록 건너뜁니다.

“로그인 필요”가 계속 뜹니다

비공개 질문이 아닌데도 반복된다면 세션이 꼬인 경우입니다. 사전작업을 다시 해서 쿠키를 새로 저장하세요.

캡차를 계속 틀립니다

캡차 풀기는 mini API → 4o API → ChatGPT 사이트 순으로 시도합니다. 계속 실패하면 그 계정은 잠시 쉬게 두고 다른 계정으로 돌리세요. 같은 계정으로 계속 시도하면 제한이 길어집니다.

하루 발행량 초과가 떴습니다

그날 그 계정으로는 더 못 올립니다. 다른 계정으로 전환하거나 다음 날까지 기다리세요. 반복된다면 발행 간격을 늘리시는 게 좋습니다.

크롬 버전업이 필요하다고 나옵니다

크롬이 업데이트되면 드라이버도 맞춰야 합니다. 프로그램이 자동으로 받아 교체하니 잠시 기다리세요. 이 과정이 매번 반복되면 프로그램을 완전히 껐다가 다시 켜보세요.

06하루 루틴

돌리기 전 한 번, 끝나고 한 번 훑으면 사고가 크게 줍니다.

돌리기 전

  • 사전작업으로 쿠키가 저장돼 있는가 (계정을 바꿨다면 필수)
  • AI 엔진이 선택돼 있고, 사이트 방식이면 로그인이 살아있는가
  • 키워드가 서로 다른 분야로 채워져 있는가
  • 발행 간격이 너무 짧지 않은가
  • 텔레그램 알림이 실제로 오는가 (점검 팝업에서 확인)

끝나고

  • 몇 개 올라갔는지 화면 로그로 확인
  • 채택률이 떨어지고 있지 않은지 지식iN 프로필에서 확인
  • “발행량 초과”나 “전문가 답변중”이 잦았다면 키워드·간격 조정
  • 답변 몇 개를 직접 열어보고 내용이 질문과 맞는지 확인
