## 설치

1. 위 **프로그램 내려받기** 에서 `gisickinLauncherV2.exe` 를 받습니다.
2. 원하는 폴더에 두고 실행하면 됩니다. 별도 설치 과정은 없습니다.
3. 처음 실행 시 Windows 경고가 뜨면 `추가 정보` → `실행` 을 눌러주세요.

실행하려면 등록된 계정이 필요합니다.

## 설명서에 담긴 내용

| 01 | 준비물 |
